# NeuroFly

Живой мозг дрозофилы для выставки. Полномозговая модель Shiu et al.
(*Nature* 2024) на коннектоме FlyWire, переписанная так, чтобы идти в
реальном времени на обычном ноутбуке без GPU, плюс экран, на котором все
139 тысяч нейронов видны как облако точек внутри контура мозга. Зритель
возбуждает и выключает нейроны, проводит свои связи и видит, как по мозгу
идёт сигнал. День посетителей оставляет в мозге след.

Из чего состоит:

* **Сеть**: 138 639 нейронов и 15,1 млн связей (54,5 млн синапсов) из
  коннектома FlyWire, релиз 783. Каждый нейрон — leaky integrate-and-fire,
  знак синапса берётся из предсказанного нейромедиатора, сила — из числа
  синапсов. Данные скачиваются при первом запуске (~105 МБ).
* **Динамика**: пошагово повторяет Brian2-модель авторов (шаг 0,1 мс,
  точное интегрирование линейных уравнений, задержка 1,8 мс, рефрактерный
  период 2,2 мс, во время которого нейрон игнорирует вход). Сверено с
  оригинальным кодом, см. ниже. С numba идёт в реальном времени на одном
  ядре обычного ноутбука; без numba есть чистый NumPy, в 8 раз медленнее.
* **Вмешательства**: `activate` (пуассоновская стимуляция с заданной
  частотой, как оптогенетика), `silence` (обнуление всех исходящих
  синапсов нейрона, цифровая лезия) и `connect` (свои синапсы поверх
  коннектома). Всё меняется на лету, не останавливая симуляцию.
* **Атлас**: для 138 625 нейронов известны координаты, тип клетки
  (8 840 типов), класс, сторона и нейромедиатор из аннотаций FlyWire
  (Schlegel et al., Nature 2024). Можно обращаться к нейронам по имени:
  `MDN`, `DNa02`, `DNp09`, `T4b`.
* **Архив**: скелеты всех нейронов, меши мозга и 75 нейропилей, все
  55,6 млн синапсов с координатами лежат в открытом облачном хранилище;
  загрузчик берёт их по требованию и кэширует для работы без сети.
* **Экран для зала**: сервер симуляции плюс страница на WebGL, где все
  139 тысяч нейронов видны как живое облако точек внутри контура мозга.
  Зритель щёлкает по нейрону, возбуждает или выключает клетки его типа,
  проводит новые связи и видит, как меняется активность.
* **Следы дня**: стимул зрителя гаснет через 20 секунд, а лезии, новые
  связи и след от использования (нейроны, которые сегодня работали,
  передают сигнал чуть сильнее) остаются до конца дня и переживают
  перезапуск. Каждая встреча меняет мозг для следующего посетителя.

Ограничения те же, что и у оригинала: нет пластичности, нет
нейромодуляции, все синапсы подогнаны одной константой `w_syn`. Модель
ничему не учится, её можно только возбуждать и повреждать.

## Установка

```bash
git clone <этот репозиторий> && cd NeuroFly
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
neurofly download        # ~105 МБ, один раз; кладёт данные в ./data
neurofly info
```

Нужен Python 3.10+. Зависимости: numpy, scipy, pandas, pyarrow.
Каталог с данными можно переопределить переменной `NEUROFLY_DATA`.

## Первый опыт: сахар → хоботок

Классический эксперимент из статьи: 21 вкусовой нейрон сахара стимулируем
на 200 Гц и смотрим на мотонейрон хоботка MN9.

```bash
neurofly run --activate sugar --rate 200 --t 1000 --trials 3 --watch mn9
```

Вывод: число спайков, список самых активных нейронов и частота MN9
(около 92 Гц). С numba одна секунда модели считается примерно за
секунду на одном ядре (для сахарного опыта), без numba за ~8 с.

Полезные варианты:

```bash
neurofly run --activate sugar --rate 100               # слабее стимул
neurofly run --activate sugar --silence 720575940622695448   # вырезать нейрон
neurofly run --activate p9 --rate 100 --top 30         # P9: команда «идти вперёд»
neurofly run --activate 720575940660219265 --rate 50   # любой FlyWire id
neurofly run --activate sugar --out results/sugar.parquet   # сохранить все спайки
neurofly --release 630 run --activate sugar            # данные из самой статьи
```

Из Python:

```python
from neurofly import load_brain, neurons

brain = load_brain(seed=1)
brain.activate(neurons.SUGAR_GRN, rate_hz=200)
spikes = brain.run(1000)               # 1 с биологического времени
print(spikes.rates().head(10))         # Гц по нейронам, id FlyWire
print(spikes.rate_of(neurons.MN9))

brain.silence(720575940622695448)      # лезия одного нейрона
brain.reset()                          # состояние в покой, вмешательства остаются
print(brain.run(1000).rate_of(neurons.MN9))
brain.clear()                          # снять все вмешательства
```

Примеры в `examples/`:

* `sugar_to_mn9.py` — сахар → MN9, затем поочерёдное выключение самых
  активных промежуточных нейронов: видно, через кого идёт сигнал.
* `interactive_windows.py` — стимулы меняются прямо во время симуляции,
  частоты считаются по скользящему окну 100 мс. Это каркас для зала.

## Экран для галереи

```bash
pip install -e ".[gallery]"
neurofly serve --port 8765
# открыть http://localhost:8765 (на этой же машине или на любой в локальной сети)
```

При первом запуске скачиваются аннотации (32 МБ) и контур мозга (4 МБ).
На экране:

* облако из 138 639 нейронов, цвет по классу (зрительная доля, центральный
  мозг, сенсорные, нисходящие, мотонейроны…), вспышка при спайке;
* режимы **Смотреть / Возбудить / Выключить / Связать**: щелчок по нейрону
  показывает, кто он, стимулирует или глушит все клетки его типа (на одной
  или обеих сторонах), два щелчка проводят новую связь заданной силы и
  знака. По умолчанию связь идёт «тип → тип»: все клетки типа источника
  соединяются со всеми клетками типа цели (не больше 4 000 пар за раз,
  лишние отбрасываются случайно); переключатель даёт связь между двумя
  отдельными нейронами;
* ползунок **время** замедляет симуляцию до 1/50 реального, чтобы волну
  спайков можно было разглядеть; на HUD видно и заданную, и фактическую
  скорость;
* кнопки готовых сценариев: вкус сахара, DNp09 «вперёд», MDN «назад»,
  DNa02 «поворот», гигантское волокно, MN9;
* для выбранного нейрона: **Связи** рисуют его входы и выходы линиями
  (зелёные возбуждающие, красные тормозные), **Синапсы** показывают
  настоящие точки контактов из архива (жёлтые выходные, синие входные),
  **Форма** подгружает настоящий скелет;
* связь, проведённая зрителем, получает свою точку контакта: ближайшая
  пара между выходными синапсами источника и входными синапсами цели;
* сверху: время модели, скорость относительно реального, спайков в
  секунду, число возбуждённых, выключенных и добавленных зрителем связей,
  счётчик вмешательств за день и лента последних действий.

### Следы дня

Сама модель ничему не учится, поэтому инсталляция добавляет три явных
правила (`neurofly/traces.py`, все числа настраиваются флагами
`neurofly serve`):

1. **Стимул — момент.** Возбуждение, включённое зрителем, само гаснет через
   `--hold` секунд (по умолчанию 20), как отпущенная кнопка. Иначе к
   вечеру весь мозг был бы включён.
2. **Лезии и связи остаются.** Выключенные нейроны и проведённые связи
   живут до кнопки «Новый день».
3. **Использование оставляет след.** Каждый спайк нейрона усиливает все
   его выходы на `--trace-alpha` (0,0001), не выше `--trace-max` (1,6);
   след спадает с постоянной времени `--trace-tau` часов (8). Пути,
   которыми сегодня пользовались, вечером проводят сигнал лучше.

Состояние (лезии, связи, следы, журнал действий) сохраняется в
`data/state/` каждые 30 секунд и восстанавливается при запуске;
`--fresh` запускает с чистого листа. Журнал доступен по `/api/journal`.

### Windows: запуск с bat-файлов

В папке `windows/` лежат сценарии для машины в зале, все запускаются
двойным щелчком:

* `install.bat` — один раз: создаёт окружение, ставит пакет, скачивает
  данные и атлас. Нужен Python 3.11 или 3.12 с галочкой «Add to PATH».
* `start.bat` — запускает сервер и открывает экран в браузере на весь
  экран (Chrome, иначе Edge). Если сервер упадёт, поднимет его снова.
  Закрыть окно сервера, чтобы остановить. Настройки в начале файла:
  порт, режим киоска, ключи сервера (`--hold`, `--fresh` и т. д.).
* `test.bat` — проверка модели и скорости.
* `synapses.bat` — один раз: таблица синапсов (2 ГБ) для настоящих точек
  контактов.

Для автозапуска положите ярлык на `start.bat` в папку автозагрузки
(`Win+R`, `shell:startup`). Выйти из киоска: Alt+F4.

### Слабое железо

Симуляция считает только «неспящие» нейроны (те, у кого есть входной
ток или которые в рефрактерном периоде), обычно это 2–15 тысяч из 139.
На одном ядре получается около реального времени для типичных
сценариев; при массовой стимуляции (тысячи нейронов) скорость падает,
и экран показывает замедленную съёмку, число на HUD «× реального»
говорит, насколько. Экрану хватает встроенной видеокарты: 139 тысяч
точек и несколько тысяч линий.

Точки синапсов требуют одноразовой сборки индекса (скачивается 2 ГБ,
на диске остаётся ещё 1,3 ГБ, оперативной памяти почти не занимает,
читается с диска кусками):

```bash
neurofly archive --synapses
```

Без индекса экран работает, просто кнопка «Синапсы» ничего не покажет.
У 5,7 % нейронов (в том числе у сахарных) в публичной таблице нет
пресинаптических точек, для них показываются только входы.

Устройство: один процесс на Python держит симуляцию в отдельном потоке
и на одном порту раздаёт страницу, атлас и меши по HTTP, а спайки и
команды гоняет по WebSocket (протокол описан в `neurofly/server.py`).
К серверу может подключиться сколько угодно экранов; TouchDesigner или
Unity могут читать тот же поток вместо браузера. Three.js лежит в
`web/vendor`, интернет странице не нужен.

Для работы без сети заранее заберите архив:

```bash
neurofly archive --meshes                 # контур мозга и 75 нейропилей, ~10 МБ
neurofly archive --skeletons 2000         # первые 2000 скелетов
neurofly archive --skeletons all          # все 139 тысяч, несколько ГБ, долго
```

Из Python атлас и архив доступны напрямую:

```python
from neurofly.annotations import Atlas
from neurofly.archive import load_skeleton, load_mesh

atlas = Atlas(brain.ids)
atlas.by_type("MDN")                 # индексы 4 нейронов «заднего хода»
atlas.search("DNa")                  # типы, содержащие строку, с числом клеток
atlas.describe(neurons.MN9)          # 'CB0701 · motor · right · acetylcholine'
brain.activate(atlas.by_type("DNa02", side="left"), 100)
brain.connect(pre, post, n_synapses=30, sign=-1)   # своя тормозная связь

skel = load_skeleton(neurons.MN9)    # узлы (мкм) и рёбра скелета
mesh = load_mesh("volume")           # контур мозга; load_mesh("MB_CA_L") и т.д.
```

## Как это устроено

`neurofly/model.py` — весь симулятор, ~150 строк логики.
Состояние: `v` (потенциал), `g` (синаптическая проводимость), время
последнего спайка. Матрица связей хранится в CSC-формате: столбец —
пресинаптический нейрон, поэтому доставка спайков сводится к сложению
нескольких столбцов, а не к умножению всей матрицы на вектор. Активность
в сети очень разреженная (сотни активных нейронов из 139 тысяч), поэтому
такой подход быстрее «честного» GPU-умножения на ноутбуке без GPU.

Один шаг (0,1 мс), в порядке Brian2:

1. интегрировать `v` и `g` у всех нерефрактерных нейронов (точная формула
   для линейной системы);
2. порог `v > -45 мВ` → спайк;
3. доставить спайки, выпущенные 1,8 мс назад (`g += w_syn · W[:, pre]`),
   и пуассоновские толчки стимулируемым нейронам; рефрактерные нейроны
   вход не получают;
4. сброс спайкнувших: `v = -52 мВ`, `g = 0`.

`neurofly/neurons.py` — курируемые наборы нейронов с известным эффектом.
Случайный нейрон почти никогда ничего не делает, начинать нужно с них.
Добавляйте свои наборы туда же (неверный id вызовет `KeyError`).

## Проверка на оригинальном коде

Тот же эксперимент (сахар, 200 Гц, 1 с) на тех же данных FlyWire 783,
оригинальный код Shiu et al. на Brian2 2.9 против NeuroFly:

| | Brian2 (3 попытки) | NeuroFly (5 попыток) |
|---|---|---|
| спайков за попытку | 16 796 | 16 881 |
| активных нейронов | 425 | 431 |
| MN9, Гц | 91,7 | 92,4 ± 2,2 |
| время на 1 с модели, одно ядро | 69 с | 8,3 с |

Разброс между попытками у самой модели такого же порядка, так что
различия в пределах шума.

Вторая сверка: данные из статьи (FlyWire 630) против готового результата
`results/example/sugarR.parquet`, который лежит в репозитории авторов
(Brian2, 30 попыток):

| | Brian2 авторов (30 попыток) | NeuroFly (10 попыток) |
|---|---|---|
| спайков за попытку | 17 052 | 17 040 |
| активных нейронов | 448 | 450 |
| MN9, Гц | 93,3 | 92,4 ± 4,0 |

Команда: `neurofly --release 630 run --activate sugar --rate 200 --trials 10`.

Чтобы повторить сверку самому, нужен отдельный venv с `numpy<2`: Brian2
не работает с NumPy 2.x, и это одна из причин, по которой NeuroFly
написан без него.

## Дальше

* **Скорость при массовой стимуляции**. Если зрителям дать включать
  целые классы (вся зрительная доля), одного ядра не хватит; тогда либо
  GPU-бэкенд (порты `eonsystemspbc/fly-brain`, `Kisame76/drosophila-brain-mlx`),
  либо ограничить размер стимулируемой группы.
* **Тело**. Мозг не содержит генератора походки. Чтобы муха «ходила», нужен
  `flygym` (NeuroMechFly) и рукописный переход от частот нисходящих
  нейронов к командам ног. Этот шов лучше показывать открыто.
* **Вспышки синапсов**. Сейчас точки контактов показываются для
  выбранного нейрона; можно подсвечивать синапсы каждого спайка в
  реальном времени, это вопрос нагрузки на экран.
* **MaleCNS**. Мужской коннектом 2026 года (166 тыс. нейронов) имеет тот же
  формат «пары нейронов + число синапсов + медиатор»; загрузчик в
  `data.py` рассчитан на добавление ещё одного релиза.
