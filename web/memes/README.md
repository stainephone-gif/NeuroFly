# Видео мемов

Положите сюда ролики. Имя файла задаётся в `web/vocab.json`, раздел `videos`:

```json
"videos": {
  "Шаурма":       "shawarma.mp4",
  "Кубик Рубика": "rubik.mp4",
  "Диджей":       "dj.mp4"
}
```

Один файл на мем: он играет по кругу без звука, поверх крупно пишется
текущее «действие» из словаря. Если нужны разные отрывки под разные
действия, вместо строки укажите объект с ключами каналов и `idle`:

```json
"Шаурма": { "idle": "shawarma_idle.mp4", "mn9": "shawarma_meat.mp4", "p9": "shawarma_knife.mp4" }
```

Формат: MP4 (H.264) или WebM. Имена файлов латиницей. Файлы в git не
попадают (папка в `.gitignore`), копируйте их на машину в зале руками.
