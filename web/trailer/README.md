# Трейлер для стартовой панели

Положите сюда файл `trailer.mp4` (H.264 + AAC, играет в Chrome и Edge).
Видео в git не хранится, копируйте его на машину в зале руками.

Панель (`web/panel/index.html`, адрес `/`) показывает кадр из трейлера на
правой кнопке и проигрывает его на весь экран. Когда трейлер доиграл или
нажата «Назад», экран возвращается на панель. Если файла нет, на кнопке
градиент, а по нажатию появляется «Трейлер сейчас недоступен».

Логотип программы: `web/panel/logo.svg` или `web/panel/logo.png`.
